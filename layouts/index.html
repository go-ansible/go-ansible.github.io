go-ansible

A pure-Go, functional-parity port of Ansible — Vault-compatible encryption, inventory parsing, the variable precedence ladder, Jinja2-compatible templating, module execution, fact gathering, the playbook engine, and all four ansible-* CLI binaries, with no Python, no C extensions, and one static binary.

CGO_ENABLED=0 byte-compatible with ansible-vault real per-host playbook execution 4 CLI binaries amd64 · arm64 · riscv64 · loong64 · ppc64le · s390x BSD-3-Clause
Documentation GitHub

Ansible's own engine is a Python program that shells out to modules and needs a matching interpreter on the control node. go-ansible reimplements that engine as importable Go packages instead of wrapping the Python binary — the same wire formats, merge orders, and rendering rules, compiled into a single static executable with no interpreter to install and no C toolchain to cross-compile against.

The bar for every component here is compatibility with the real thing, not a plausible reimplementation of it: vault reproduces ansible.parsing.vault.VaultAES256's exact byte format, and template implements the native-type rendering rule that trips up naive Jinja2 ports. All eight core repositories below are shipped and tagged; parity is still partial — see the module count and the engine feature matrix further down this page for exactly what that does and doesn't cover today, re-checked against the code rather than assumed.

Engine feature matrix

The silent-no-op class — a playbook key that parses without error but does nothing — is a worse risk than an outright missing feature, since a playbook using it succeeds while quietly not doing what it claims. This table reflects playbook/engine.go and playbook/playbook.go as read directly, not the shipped-package list: several of these fields exist on the Play/Task structs and parse cleanly from YAML while the engine never reads them.

Playbook featureStatusDetail
when / loop / registerImplementedPer-host, real conditionals and loop expansion
block / rescue / alwaysImplementedGenuine per-host recovery, not just parsed
notify / handlersImplementedDeduplicated, run once per host after the play
becomeImplementedReal sudo end-to-end test in CI
pre_tasks / post_tasksImplementedConcatenated into the task list in pre → tasks → post order and executed normally
rolesNot yetReserved key only — no Role type, no role-directory execution at all
tags / --tags, --skip-tagsNot yetParsed onto Play and Task, but no filtering logic anywhere and no CLI flags
delegate_toNot yetA real field on Task, parsed, never read by engine.go — the task always runs on its original host
serialNot yetA real field on Play, parsed, never read by engine.go — every play runs all hosts at once
vars_filesNot yetRecognized as a reserved key; the referenced files are never loaded
strategyNot yetReserved key only; execution is always the linear strategy
include_tasks / import_tasks / include_role / import_roleNot yetNot parsed at all

Also out of scope today: the collections/namespace system, dynamic inventory plugins, lookup/callback plugins, ansible.cfg, and four of Ansible's own CLI tools (ansible-doc, ansible-config, ansible-pull, ansible-console). ansible-galaxy here only clones a role from a git URL — no galaxy.ansible.com API, no collections. This matrix reflects the code as read on 2026-09-02; engine work is active in parallel, so treat it as a snapshot, not a promise.

Module coverage

modules/registry.go registers 20 module names (19 distinct implementations — service is systemd's classic alias, not a separate module) against ansible.builtin's 71 modules, counted via ansible-doc -l -t module against a real ansible-core 2.21.3. The scoped target for this port is a core set of roughly 40–60 modules, not the full 3000+-module surface of Ansible plus its collections.

Dependencies

The low-level connection layer — SSH, local execution, become/sudo — lives outside this org, in go-remoteexec/transport, a project-neutral package shared with go-puppet-bolt/bolt. modules, playbook, and cli depend on it directly rather than shipping their own transport.
